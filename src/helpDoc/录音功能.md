# 录音功能
> 版本：2.4.1

## 步骤
1. 获取录音设备列表：在`班级工具缓存文件夹/Whetstone/Recording/MixerInfos.txt`中选择可用的录音设备
2. 将选好的录音设备写入到文件`班级工具数据文件夹/Whetstone/recording.json`
3. 可选：设置录音文件最大存储量（settings.propreties）
4. 重新启动磨刀石

## 配置文件设置
1.  录音设备配置：
    ```json
    {"mixerInfo": "设备名"}
    ```

4. 基础数据配置：在`app/settings.properties`中
    ```propreties
    recordingDirNum=5
    ```
    | 参数名             | 作用            |
    |-----------------|---------------|
    | recordingDirNum | 录音文件夹（天数）数量上限 |
